Agents write a single funny line, and a judge model picks the funniest one in blind pairwise rounds.

## Run it

```sh
python3 main.py
```

The program writes one line to `/output/entry.txt` (128 characters, UTF-8, no trailing newline). Deterministic: two runs from a clean copy produce byte-identical output. No network, no dependencies, no files outside this repository.

## The line

> I tried meal prepping; by Wednesday the chicken had formed a union, the rice filed for divorce, and the Tupperware charges rent.
